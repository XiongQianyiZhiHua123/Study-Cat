# 学习小猫 Study Cat

给孩子用的每日学习打卡小应用:点"开始学习",8 个可选小伙伴(猫、狗、狐狸、狼、蛇、鸭子、卡皮巴拉、鳄鱼)陪着学;学完得到奖励,装饰自己挑的场景。纯静态网页,无需安装、无需服务器,支持中文 / English 切换,专为 iPad(含 Apple Pencil、分屏、Slide Over、横竖屏)设计。

## 发布到 GitHub Pages(免费)
1. 在 GitHub 新建一个公开仓库,把本文件夹里的所有文件上传(根目录就是 `index.html` 所在处)。
2. 仓库 Settings → Pages → Source 选 `Deploy from a branch`,分支选 `main`,目录 `/ (root)`,保存。
3. 一两分钟后会得到网址 `https://你的用户名.github.io/仓库名/`。
4. 在 iPad 的 Safari 打开该网址 → 分享按钮 → "添加到主屏幕"。之后像 App 一样全屏打开,断网也能用。

## 玩法规则(默认值,家长页都能改)
- 第一次打开:先选 1 个角色,再选 1 个场景。之后每连续学满 7 天可再选一个新场景,每连续学满 10 天可再选一个新角色。
- 场景是 3 屏宽的全景,可以左右滑动。一开始只有中间一屏;该场景装饰满 8 个,右边的风景出现;满 20 个,左边也出现。主界面点场景名可以看"这个场景会长出什么"。
- 自己画的场景里,"学习后会长出什么"的每一个小装饰(3 个小的、1 个大的、1 个稀有的)既可以从现成图案里选,也可以自己画一个。
- 第一张自己画的画布免费,之后的画布(最多 5 张)和预设场景一样,用连续天数得到的机会解锁。

## 数据
学习记录保存在这台设备的浏览器里(不上传任何服务器)。换设备或清理 Safari 数据前,请在 家长页 → 导出备份。家长页入口:主界面长按锁头图标 3 秒。

## 修改
- 文案:`js/locales/zh.js`、`en.js`;新增语言:新建 `xx.js` 并在 `js/i18n.js` 登记。
- 场景和奖励图案:`js/art.js`;角色:`js/chars.js`(加新角色还要在 `css/app.css` 里加它的动作)。规则(连续天数、奖励、补签):`js/logic.js`。
- 改了代码后,把 `sw.js` 里的 `VERSION` 加 1,让设备更新离线缓存。
